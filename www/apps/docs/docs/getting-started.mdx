## Requirements

- **Linux** on x86_64 or arm64.
- A **[Nerd Font](https://www.nerdfonts.com/)** set as your terminal's font. Without one, icons show as boxes.
- For image previews: **kitty**, **WezTerm**, or another terminal with sixel support. See [Previews](/previews#images).

## Install

<Tabs>
  <Tab title="Install script">
    ```bash
    curl -fsSL https://nukri.urdadx.com/install.sh | sh
    ```

    This installs `nukri` to `/usr/local/bin`, or `~/.local/bin` if that isn't writable, and adds it to your app menu. It then offers to install the optional [preview tools](/previews#tools).

    | Variable | Effect |
    | --- | --- |
    | `NUKRI_VERSION=0.1.0` | Install a specific version instead of the latest |
    | `NUKRI_INSTALL_DIR=~/bin` | Install to this folder |
    | `NUKRI_INSTALL_TOOLS=yes` or `no` | Install the preview tools, or skip them, without asking |

    Set them before `sh`:

    ```bash
    curl -fsSL https://nukri.urdadx.com/install.sh | NUKRI_VERSION=0.1.0 sh
    ```

  </Tab>
  <Tab title="Go">
    Needs Go 1.25 or newer.

    ```bash
    go install github.com/urdadx/nukri/cmd/nukri@latest
    ```

    This installs to `~/go/bin`. Make sure it's on your `PATH`.

  </Tab>
</Tabs>

Check it works:

```bash
nukri -version
```

## First run

Run `nukri` in any folder. You get three panes:

- **Places** (left): your home folders, mounted drives, and the trash.
- **Files** (middle): the current folder.
- **Preview** (right): the selected file or folder.

## The keys you need first

| Key | Action |
| --- | --- |
| `j` `k` or `↓` `↑` | Move |
| `Enter` | Open a folder or file |
| `h` or `←` | Go up a folder |
| `Space` | Mark an item |
| `y` `x` `p` | Copy, cut, paste |
| `d` | Move to trash |
| `f` | Find a file |
| `T` | Change theme |
| `q` | Quit |

The mouse works too: click to select, double-click to open, scroll to move.

All keys are in [Keyboard shortcuts](/keys).
