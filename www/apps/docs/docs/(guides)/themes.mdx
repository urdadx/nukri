## Pick a theme

Press `T`. Move through the list with `↑` `↓` and the theme previews live.

- `Enter` keeps it. Nukri saves it to [`config.toml`](/configuration).
- `Esc` goes back to the theme you had.

To try a theme for one session without saving it:

```bash
nukri -theme nord
```

## Built-in themes

`0x96f`, `ayu-dark`, `blood`, `catppuccin-frappe`, `catppuccin-latte`, `catppuccin-macchiato`, `catppuccin-mocha` (default), `dracula`, `everforest-dark-hard`, `everforest-dark-medium`, `gruvbox`, `gruvbox-dark-hard`, `hacks`, `kaolin`, `monokai`, `nord`, `onedark`, `poimandres`, `rose-pine`, `sugarplum`, `tokyonight`.

## Make your own

<Steps>
  <Step title="Create the file">
    Save a `.toml` file in `~/.config/nukri/themes/`. The file name is the theme name: `mytheme.toml` is `mytheme`.

    The easiest start is copying a [built-in theme](https://github.com/urdadx/nukri/tree/main/configs/themes).
  </Step>
  <Step title="Set the colors">
    Use `#rrggbb` hex colors. Only `full_screen_fg` and `full_screen_bg` are required.
  </Step>
  <Step title="Use it">
    Press `T` and pick it, or run `nukri -theme mytheme`.
  </Step>
</Steps>

A file with the same name as a built-in theme replaces it.

### Example

```toml title="~/.config/nukri/themes/mytheme.toml"
code_syntax_highlight = "dracula"

full_screen_fg = "#f8f8f2"
full_screen_bg = "#282a36"

file_panel_fg = "#f8f8f2"
file_panel_bg = "#282a36"
file_panel_border = "#6272a4"
file_panel_border_active = "#44475a"
file_panel_top_directory_icon = "#50fa7b"
file_panel_top_path = "#8be9fd"
file_panel_item_selected_fg = "#ffb86c"
file_panel_item_selected_bg = "#282a36"

footer_fg = "#f8f8f2"
footer_bg = "#282a36"

sidebar_fg = "#f8f8f2"
sidebar_bg = "#282a36"
sidebar_item_selected_fg = "#ffb86c"
sidebar_item_selected_bg = "#282a36"
sidebar_divider = "#868686"

modal_fg = "#f8f8f2"
modal_bg = "#282a36"
modal_border_active = "#44475a"

correct = "#50fa7b"
cancel = "#6272a4"
```

### Keys

| Key | Colors |
| --- | --- |
| `full_screen_fg` | Default text. **Required.** |
| `full_screen_bg` | Background. **Required.** |
| `file_panel_fg`, `file_panel_bg` | File list and preview text and background |
| `file_panel_border` | Preview and places borders |
| `file_panel_border_active` | File list border and the selected-row marker |
| `file_panel_top_path` | Pane titles, the current path, and status bar highlights |
| `file_panel_top_directory_icon` | Icons in places and the preview |
| `directory_icon_color` | Folder icons in the file list. Defaults to `file_panel_top_directory_icon`. |
| `file_panel_item_selected_fg`, `file_panel_item_selected_bg` | The selected file |
| `sidebar_fg`, `sidebar_bg` | Places pane |
| `sidebar_item_selected_fg`, `sidebar_item_selected_bg` | The selected place |
| `sidebar_divider` | Dimmed text: details, hints, the status message |
| `footer_fg`, `footer_bg` | Status bar. `footer_bg` defaults to `full_screen_bg`. |
| `modal_fg`, `modal_bg` | Dialogs |
| `modal_border_active` | Dialog border and title |
| `correct` | Items you copied with `y` |
| `cancel` | Items you cut with `x`, and error text |
| `code_syntax_highlight` | Code preview style. Any [Chroma style](https://github.com/alecthomas/chroma/tree/master/styles) name, such as `monokai` or `github`. |

Other keys are ignored. A key you leave out uses the terminal's default color.

:::note
Nukri keeps selected rows and dialog text readable. If a color has too little contrast against its background, Nukri swaps in a more readable one.
:::

## If a theme doesn't load

- With `-theme`, Nukri prints the error and exits. A typical one is `theme "x" not found`.
- If the theme saved in `config.toml` is broken or missing, Nukri silently starts with `catppuccin-mocha`.
