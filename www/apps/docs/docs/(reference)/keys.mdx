---
title: Keyboard shortcuts
description: Every key in Nukri, by where you use it.
---

Keys can't be remapped yet.

## Browsing

| Key | Action |
| --- | --- |
| `j` / `↓` | Down |
| `k` / `↑` | Up |
| `Enter` | Open folder or file |
| `h` / `←` / `Backspace` | Parent folder |
| `Alt+←` / `Alt+→` | Back / forward |
| `Tab` / `Shift+Tab` | Next / previous place |
| `f` | Find in the current folder tree |
| `P` | Show / hide the preview |
| `PgDn` / `Ctrl+D` | Scroll preview down |
| `PgUp` / `Ctrl+U` | Scroll preview up |
| `T` | Theme picker |
| `q` / `Ctrl+C` | Quit |

## Files

| Key | Action |
| --- | --- |
| `Space` | Mark and move down |
| `Esc` | Clear marks, then the copy or cut |
| `y` | Copy |
| `x` | Cut |
| `p` | Paste |
| `a` | Create files or folders |
| `r` / `F2` | Rename (in Trash: restore) |
| `R` / `Shift+F2` | Rename in your editor |
| `d` / `Delete` | Move to trash (in Trash: delete permanently) |
| `D` / `Shift+Delete` | Delete permanently |
| `C` | Create an archive |
| `e` | Extract an archive |
| `o` | Open with the default app |
| `O` | Open with… |
| `c` | Copy name or path |
| `Alt+D` | Find duplicates |

## Mouse

| Action | Effect |
| --- | --- |
| Click | Select a file, or open a place |
| Double-click | Open |
| Scroll over the list | Move the selection |
| Scroll over the preview | Scroll the preview |

## In text fields

Used when creating and renaming.

| Key | Action |
| --- | --- |
| `Enter` | Confirm |
| `Esc` | Cancel |
| `Alt+Enter` / `Ctrl+J` | New line (create only) |
| `↑` `↓` / `Tab` `Shift+Tab` | Previous / next line |
| `Home` / `Ctrl+A`, `End` / `Ctrl+E` | Start / end of line |
| `Ctrl+U` / `Ctrl+K` | Delete to start / end of line |

## In lists and dialogs

| Where | Keys |
| --- | --- |
| Theme picker, Open with, Copy path | `j` `k` / `↑` `↓` move, `Enter` choose, `Esc` cancel |
| Copy path | `n` name, `s` name without extension, `p` full path, `d` folder path |
| Confirmations | `y` / `Enter` yes, `n` / `Esc` no |
| Find | Type to search, `↑` `↓` / `Ctrl+P` `Ctrl+N` move, `Enter` go, `Esc` close |
| Duplicates | `j` `k` move, `d` trash this copy, `Enter` go to file, `Esc` close |
